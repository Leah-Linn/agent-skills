# cust-resume-skill

**给一份 JD，先搞清它到底要什么人，再决定简历怎么写。**

面向海外销售岗位的简历定制化 skill

</div>

---

## 为什么需要这个

「海外销售」是一个岗位名，不是一份工作。同一个名字底下，藏着几种能力模型互不相通的活。

一个真实的招聘失败：某公司招了一批**安防头部大厂**出来的海外渠道销售，结果不好用。同行业、同岗位名、经验更丰富——但他们原来的渠道早已进入稳定期，日常做的是渠道管理和赋能，没做过 0-1 开发，来了非常受挫。

**不是能力差，是阶段不匹配。**

所以简历定制不是包装术，是回答一个具体问题：**你是不是我这一格的人。**

---

## 核心方法：四轴坐标

拿到 JD 先定坐标，坐标定完才知道简历该往哪改。

### 轴一 · 渠道销售 还是 大客户销售

判定标准只有一条：**中间有没有代理商。**

```
公司 → 代理商 → 终端用户   = 渠道销售
公司 → 终端用户            = 大客户销售
公司 → 电商平台 → 消费者    = 电商运营（不是海外销售）
```

### 轴二 · 公司出海处在哪个阶段

| 阶段 | 公司在干什么 | 要什么人 |
|---|---|---|
| 0-1 开荒 | 一个代理都没有 | 能从零找人、抗拒绝、自己搞线索 |
| 1-10 发展 | 有几个代理但网络不全 | 一边继续拓，一边帮代理动销 |
| 10-100 稳定 | 网络成型 | 本地化运作、精细化、带团队 |

### 轴三 · 终端客户是 B 还是 C

⚠️ 这一轴**只用来细分渠道销售**——大客户销售本来就直接面对终端。

```
渠道销售 ─┬─ 终端是 B → 还得懂大客户那一套（要陪代理商去啃终端企业）
          └─ 终端是 C → 管终端门店 + KA 卖场
```

### 轴四 · 线索从哪来

JD 通常不写，但最影响简历主打什么。

| 信号 | 简历该主打 |
|---|---|
| 提展会、广告投放、市场部、MDF | **转化能力** |
| 只强调「独立开发」「自主拓展」 | **自拓能力** |

## 流程

```
P1   拆 JD → 四轴坐标（每条判定标注信源与置信度）
      ↓
P1b  信号不足 → 兜底查（社招岗 JD / 官网 / 年报 / 岗位结构）
      ↓
P2   输出「岗位画像卡」 ⏸ 停下来等确认      ← 坐标判错，后面全白改
      ↓
P3   从素材库选料 + 换取景框 + 卡字数预算
      ↓
P4   真实性溯源校验                          ← 见下
      ↓
P5   按槽位输出文本 + 溯源表 + 改动说明
```

### 关于 P4：为什么要溯源

每条改写后的 bullet 必须能**指回素材库的原始条目和原始数字**，产出一张对照表：

| 简历上写的 | 来自素材库 | 原始事实 | 被追问时怎么答 |
|---|---|---|---|

**规则不可协商：素材库里没有的数字和事实，一律不写。**

面试前把这张表过一遍，每句话背后都有真事——追问三层也穿不了。

某个坐标格需要的能力如果确实没有素材，**如实标成空缺**，建议用「认知层」去补，不硬凑。

## 一个针对校招的特殊处理

校招 JD 通常写成「负责海外市场开拓与客户维护，完成销售目标」——**四个轴一个都判不出来**。这不是读得不够仔细，是校招 JD 本来就面向一批人而不是一个岗。

解法：**从读 JD 换成读公司。**

| 想知道 | 去哪查 |
|---|---|
| 渠道还是大客户 | 官网有没有 Distributor / Partner / Where to buy 页 |
| 出海阶段 | 年报里海外营收占比和增速、海外有几个子公司 |
| 终端 B 还是 C | 官网案例页看客户是企业还是个人 |
| 线索来源 | 有没有博客、白皮书、展会新闻；招不招 marketing |

上市公司尤其好查，年报里分区域收入是公开的，比 JD 有用得多。

## 安装

```bash
git clone <this-repo> ~/.claude/skills/cust-resume-skill
```

或放到项目级的 `.claude/skills/`。

## 配置

```bash
cd ~/.claude/skills/cust-resume-skill
cp config.example.md config.md
```

编辑 `config.md`，填入：

- **素材库路径** —— 你的简历素材母版（唯一素材来源）
- **简历模板路径** —— 用于测量槽位与字数预算
- **求职背景** —— 毕业时间 / 校招或社招 / 目标行业 / 目标地区 / 所在城市

⚠️ `config.md` 已在 `.gitignore` 里，不会被提交。

### 前置：你需要一份简历素材库

这个 skill 的输入不是你的简历，是**素材库**——所有经历、所有数字的母版，只增不减、永不投递。每次投岗位时从里面切。

没有的话先建一份，结构见 `config.example.md`。**这是整条流水线的弹药**，素材库空的话 skill 跑不出东西来。

### 前置：测量你的模板

不同简历模板结构差别很大（文本框排版 vs 普通段落），字数预算必须实测。`references/slots.md` 里有测量脚本。

## 底线

**不编造。** 不虚构经历、数字、项目。

理由是实用的，不是道德的：海外销售面试会往下追三层，编的撑不到第三层；行业圈子小，被戳穿一次的代价远大于多约到一个面试。

真实素材写不出来，通常不是素材不够，**是没提炼过**。

---

## 方法论出处

四轴里的**渠道 vs 大客户**、**公司出海三阶段**、以及「JD 要结合出海阶段来判断能力匹配」这个核心思路，来自 **雨哥（雨哥聊海外销售）** 的海外销售体系课。安防大厂那个招聘失败的案例也出自该课程。

本 skill 是把这套判断方法工程化成可执行流程，方法论版权归原作者。
