# 配置示例

复制本文件为 `config.md` 并填入你自己的信息。`config.md` 已在 `.gitignore` 中，不会被提交。

| 配置项 | 你的路径 |

| **素材库** | `~/path/to/简历素材库.md` |
| **简历模板** | `~/path/to/your-resume.docx` |

## 求职背景

⚠️ 这一段直接决定定制方向，务必填准。

```yaml
毕业时间:  20XX 年
求职类型:  校招 / 社招 / 实习        # 写错会投错池子
目标岗位名: 例如 海外渠道销售 / 海外大客户经理
目标行业:  例如 机器人 / 工业自动化 / 消费电子
目标地区:  例如 欧洲 / 东南亚 / 北美
所在城市:  例如 深圳
外派意愿:  接受长期外派 / 仅接受出差 / 不接受
语言:      例如 英语（雅思 X）、日语 NX
简历语言:  中文 / 英文 / 中英双语
投递渠道:  招聘平台官网 / BOSS 直聘 / 猎聘 / 邮件 / 内推
到岗信息:  实习填写每周天数、最早到岗日和可持续周期；校招/社招填写最早到岗日
```

## 素材库应有的结构

本 skill 假设你的素材库按下面的方式组织。没有的话先建一份——**这是整条流水线的弹药**。

```markdown
# 简历素材库（母版）

> 只增不减，永不投递。每次投岗位时从这里切出投递版。

## A. 实习经历一 · <公司> · <岗位> · <起止>
### A1 · <素材小标题>
- 事实
- 可量化数字
- 🔗 框架映射：对应销售流程的哪一步
- 🎯 适配：什么坐标格的岗位用得上
- ⚠️ 待补：还缺什么数字

### A2 · ...

## B. 实习经历二 · ...

## C. 涉外 / 展会经历

## D. 学生组织 / 领导力

## E. 教育背景

## F. 待补清单

## G. 投递版切法速查
| 目标坐标 | 必带素材 | 可砍 |
```

**关键约定**：
- 每条素材有唯一编号（A1 / B2 / C1…），供溯源表引用
- 每条素材记录**原始事实**和**原始数字**——这是 P4 溯源校验的依据
- 缺数字的地方写明「待补」，**不要留空让人误以为有**

## 简历模板的槽位测量

首次使用前，先按 `references/slots.md` 里的脚本测量你自己简历模板的槽位和字数预算，把结果填回 `slots.md`。

不同模板的结构差别很大（文本框排版 vs 普通段落），字数预算必须实测，不能照抄。
