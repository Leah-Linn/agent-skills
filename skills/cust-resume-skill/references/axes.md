# 四轴判定表

判定顺序固定：**先轴一（渠道/大客户），再轴二（阶段），轴三只在轴一=渠道时才用，轴四贯穿始终。**

---

## 轴一 · 渠道销售 还是 大客户销售

**判定标准只有一条：中间有没有代理商。**

```
公司 → 代理商 → 终端用户   = 渠道销售
公司 → 终端用户            = 大客户销售
公司 → 亚马逊 → 消费者      = 电商运营（不是海外销售，另一套能力）
```

| JD 里出现 | 判定 |
|---|---|
| distributor、dealer、reseller、代理商、经销商、分销、渠道政策、返点、区域保护、sell in / sell out、渠道拓展、渠道管理 | **渠道型** |
| KA、大客户、项目跟踪、招投标、tender、解决方案、方案交付、KP、客户经理、项目周期、POC | **大客户型** |
| 亚马逊、店铺运营、listing、选品、广告投放 ROI、跨境电商 | **电商运营**（排除） |
| 系统集成商、SI、行业客户 | 渠道型 + 终端是 B |

⚠️ **混合信号很常见。** 「新客户开发 + 大客户维护 + 项目跟踪」这种组合，且全文零出现代理商 → 判为**大客户型**。有代理商字样才算渠道型。

### 判定后的含义

| | 渠道销售 | 大客户销售 |
|---|---|---|
| 核心工作 | 开发和管理代理商 | 啃单个项目、打通决策链 |
| 复利 | 拿下 A 代理 = 拿下他整张二级网 | 每个客户从 0 重来 |
| 简历该突出 | 批量开发、画像筛选、渠道管理 | 决策链梳理、长周期跟进、多方协调 |

## 轴二 · 出海阶段

| 阶段 | JD 信号词 | 公司在干什么 | 要什么人 |
|---|---|---|---|
| **0-1 开荒** | 开拓、从 0 到 1、拓展新市场、独立负责、开发新客户、频繁出差、抗压、能吃苦 | 一个代理都没有 | 能从零找人、抗拒绝、自己搞线索 |
| **1-10 发展** | 渠道管理、代理商赋能、动销、提升份额、复购、区域深耕、既有客户+新增 | 有几个代理但网络不全 | 一边继续拓，一边帮代理动销 |
| **10-100 稳定** | 本地化、精细化运营、团队管理、跨部门协同、国家经理、区域负责人、体系建设 | 网络成型 | 本地化运作、带团队 |

### 辅助判据（JD 说不清时）

- **列了出差国家清单** → 已有业务落点，不是纯 0-1
- **有「规划区域市场销售计划」这类表述** → 已有「区域」概念，至少 1-10
- **同时出现成熟市场（美德英）和新兴市场（东南亚）** → 很可能一个岗位跨两个阶段，要在画像卡里标出来
- **上市公司 + 千人规模** → 一般不会是纯 0-1

⚠️ 同一家公司不同国家可以处在不同阶段。要判的是**这个岗位负责的那个市场**。

## 轴三 · 终端是 B 还是 C

⚠️ **这一轴只用来细分渠道销售。** 大客户销售本来就直接面对终端，不需要再分叉。

```
渠道销售 ─┬─ 终端是 B → 还得懂大客户那一套（要陪代理商一起去啃终端企业）
          └─ 终端是 C → 管终端门店 + KA 卖场
```

| JD 信号 | 判定 |
|---|---|
| 系统集成商、行业客户、方案交付、企业客户、B 端 | 终端 B |
| 零售、门店、卖场、商超、消费者、C 端、电商 | 终端 C |

⚠️ **KA 这个词有歧义**：
- B2B 语境 = Key Account（大客户，如一家连锁酒店集团）
- 零售语境 = 重点卖场（如 Best Buy）

看上下文判断，别混。

## 轴四 · 线索从哪来

**JD 通常不写，但最影响简历主打什么。**

| JD 信号 | 判定 | 简历该主打 |
|---|---|---|
| 展会、广告投放、市场推广活动、marketing、MDF、线索分配、市场部支持 | **公司给线索** | **转化能力**（成交数、议价、谈判） |
| 独立开发、自主拓展、自行开发客户，且全文不提营销投入 | **靠自拓** | **自拓能力**（筛选量、线索库、触达量） |
| 两者都提 | 混合 | 两条都写，转化在前 |

### 为什么这一轴重要

课程里的一个案例：他做家用摄像头时，同期进来 **5-6 个带着安防行业资源的销售，最后只有他留下来**——因为公司线索不够，他自己用领英把客户拓出来了。

**对零行业资源的候选人，「靠自拓」的岗位反而更有戏。**
