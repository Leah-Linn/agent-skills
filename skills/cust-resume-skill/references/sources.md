# 兜底信源清单

**什么时候用**：四轴里任何一个判不出来。校招 JD 极常见——它写成「负责海外市场开拓与客户维护，完成销售目标」，四个轴一个都判不出来。

**这不是 JD 读得不够仔细，是校招 JD 本来就面向一批人而不是一个岗。**

解法：**从读 JD 换成读公司。**

---

## 按优先级查

### ① 该公司的社招岗 JD（最高性价比）

社招 JD 写得比校招具体得多，因为它招的是一个具体的坑。

- 在 BOSS 直聘 / 猎聘搜该公司名，看**所有**在招岗位
- 重点看：海外销售、区域经理、渠道经理、海外市场、国际业务
- 也看**周边岗位**——招不招 marketing / 海外售后 / 海外技术支持，这本身就是信号

### ② 官网

| 查什么 | 说明什么 |
|---|---|
| 有没有 **Distributor / Partner / Where to buy** 页面 | 有 = 渠道型；只有「联系销售」= 大客户型 |
| **案例页 / Customer Stories** | 客户是企业还是个人 → 终端 B/C |
| **Newsroom / 新闻动态** | 参加什么展会、在哪些国家有动作 → 出海阶段 + 线索来源 |
| **有没有多语言站点、哪些语言** | 重点市场在哪 |
| 有没有**博客 / 白皮书 / 资料下载** | 有 = 做内容营销 = 公司给线索 |

### ③ 年报 / 财报（上市公司专属，含金量最高）

- **海外营收占比 + 增速** → 出海阶段最硬的证据
- **分区域收入** → 哪些市场是重点
- **海外子公司数量和位置** → 有子公司 = 至少 1-10，多半 10-100
- **销售模式描述**（经销 / 直销占比）→ 直接回答轴一

上市公司在巨潮资讯网、公司官网「投资者关系」都能查到。

### ④ 招聘平台上的岗位结构

看这家公司同期在招什么：

| 在招 | 说明 |
|---|---|
| 海外 marketing / 品牌 | 有营销投入 → 公司给线索 |
| 海外技术支持 / 售后 | 产品复杂、重服务 → 大概率 B 端、可能 B2B2B |
| 海外仓 / 物流 | 有备货 → 至少 1-10 |
| 只招销售，别的都不招 | 资源少 → 靠自拓 |

## 信源标注要求

兜底查到的每条结论，**必须标注**：

```
| 判定 | 依据 | 类型 | 置信度 |
|---|---|---|---|
| 渠道型 | 官网有 Where to Buy 页，列了 12 个国家的经销商 | 官网推断 | 中 |
| 1-10 发展期 | 2025 年报：海外收入占比 18%，同比 +45% | 年报数据 | 高 |
```

**类型分三档，不许混**：
- `JD 明写` —— 直接引用原句
- `官网/年报推断` —— 有据可查但不是招聘方说的
- `经验假设` —— 没有证据，纯行业常识推测（⚠️ 必须显式标出，让用户自己判断）

## 需要系统调研时

调用 **`company-research` skill**（五看六定框架，同样出自雨哥海外销售课，若已安装），不要在这里重复实现一套市场调研。

本 skill 只需要拿到够判四轴的信息即可，不需要完整市场调研报告。
