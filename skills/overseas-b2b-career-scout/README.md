# overseas-b2b-career-scout

**把行业研究变成一张真正能投递的海外 B2B 销售求职地图。**

面向欧洲、新加坡和马来西亚的公司筛选、岗位判断与实时 JD 调研 Skill

</div>

---

## 为什么需要这个

看起来很强的公司，不一定适合做职业起点；写着“海外销售”的职位，也不一定能积累真正的海外销售能力。

这个 Skill 不只回答“行业好不好”，而是继续追问：

- 产业链中哪个环节最适合进入？
- 哪些公司既有竞争力，也能让销售接触高质量客户和复杂项目？
- 哪些职位是真正的区域经营、方案销售或渠道开发，哪些只是报价、跟单和出货？
- 以候选人的当前背景，哪些公司现在能进，哪些更适合作为第二跳？
- 公开招聘中，哪些具体 JD 仍然有效并可以直接申请？

最终目标不是写一篇行业论文，而是形成一份可以马上开始行动的求职作战地图。

## 默认输出什么

### 1. 30 秒结论

直接说明最佳产业链入口、最现实的第一站、最有价值的第二站，以及应该避开的岗位。

### 2. 分级公司池

通常整理 25–40 家公司，并按投递价值分成：

| 级别 | 含义 |
|---|---|
| A 档 | 每周查看，出现匹配岗位就优先投递 |
| B 档 | 国家、岗位内容和个人背景匹配时再投 |
| C 档 | 补充观察，不排在前两档之前 |

每家公司会说明核心环节、值得寻找的职位、目标地区、职业价值、进入门槛和官方关注入口。

### 3. 按候选人背景分流

区分应届生、2–5 年项目销售、技术转销售、欧洲语言与工作权持有者，以及新加坡本地候选人，避免用同一张榜单回答所有人。

### 4. 实时招聘结果

报告最后集中列出已核验的具体职位，包括：

- 公司与准确岗位名称；
- 实际工作地和负责区域；
- 经验、语言和工作权门槛；
- 招聘状态与核验日期；
- 可直接进入具体 JD 的申请链接；
- 匹配判断和投递前必须确认的风险。

招聘首页、公司主页和搜索结果不能冒充实时 JD。已经关闭、过期、重复或地域不合适的职位不会进入实时招聘表。

## 地域规则

| 地域 | 处理方式 |
|---|---|
| 欧洲、新加坡、马来西亚 | 优先研究和排序 |
| 泰国、越南、印度尼西亚 | 仅保留理由明确、质量很高的例外 |
| 菲律宾、柬埔寨、缅甸 | 不推荐 |

`SEA`、`APAC`、`International` 只是职位标题，不代表地域合格。Skill 会继续核验实际国家、客户收入分布、出差范围和本地支持资源。

## 核心判断方法

```text
行业与产业链
    ↓
找到技术、客户和交易价值更高的销售入口
    ↓
建立龙头、挑战者、隐形冠军、分销商和集成商公司池
    ↓
核验欧洲 / 新马的本地实体、渠道、服务和客户基础
    ↓
判断岗位是真销售、方案销售、渠道经营，还是低价值跟单
    ↓
搜索并逐一打开具体 JD，核验是否仍可申请
    ↓
输出公司优先级、个人投递路线和实时岗位直达链接
```

公司实力、海外销售职业价值和当前进入现实性始终分开判断。知名公司不会因为名气自动排在前面。

## 底线

**不把“搜到”当成“在招”，不把“公司很强”当成“岗位适合”，不把宽泛地域名称当成真实市场归属。**

所有推荐都必须能回到具体公司、具体岗位、具体地域和可核验的证据。
